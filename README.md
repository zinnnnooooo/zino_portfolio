## 📣 Marketing Experience

브랜드와 기관의 메시지가 소비자에게 효과적으로 전달될 수 있도록 **콘텐츠 기획부터 운영까지 직접 연결하는 마케팅 실무**를 경험했습니다.

공공기관 SNS 운영, 콘텐츠 기획 및 제작, 공공입찰 제안서 작성과 수주, 인플루언서 협업, 온·오프라인 프로젝트 등 다양한 과업을 수행하며 **브랜드의 언어를 사람들의 시선에 맞게 전달하는 방법**을 고민해왔습니다.

## ⚽ Personal Content

좋아하는 축구를 직접 콘텐츠로 만들고 SNS 채널을 운영하며 **기획 → 디자인 → 업로드 → 커뮤니케이션 → 채널 운영**의 전 과정을 경험했습니다.

단순히 콘텐츠를 제작하는 것을 넘어, 사람들이 어떤 이야기에 반응하고 무엇을 함께 이야기하고 싶어 하는지 관찰하며 **콘텐츠와 커뮤니티가 연결되는 과정**을 직접 만들어가고 있습니다.

## 🤖 AI Vibe Coding

아이디어를 기획서나 디자인에서 멈추지 않고 **AI와 바이브 코딩을 활용해 실제 웹과 앱으로 구현**합니다.

### SimSPEND

충동구매를 막아주는 새로운 소비 경험을 제공하는 개인재무 서비스.

### UNI:CITY

정품 유니폼을 보다 쉽고 안전하게 구매할 수 있도록 설계한 축구 유니폼 이커머스.

### National Museum of Korea

문화유산을 현대적인 디지털 경험으로 재해석한 국립중앙박물관 웹사이트 리디자인.

AI를 단순한 코드 생성 도구가 아니라 **기획과 디자인에서 상상한 경험을 실제 결과물로 연결하는 협업 도구**로 활용합니다.
